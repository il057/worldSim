# 07 长程推演质量评估与基准报告规范 (docs/07_EVALUATION_AND_BENCHMARK.md)

本文档规范了系统在经历 100+ 刻长跨度推演后的**长程一致性验证**、**拟真生活节律自动化调度**与**单文件独立 HTML 评测可视化报告**架构体系。

---

## 1. 核心评估四大维度规范 (Four-Dimension Evaluation Matrix)

长程推演（100 刻）的质量验证杜绝依赖纯人工肉眼抽检，系统采用工业级 **LLM-as-a-Judge（大模型裁判）** 与客观时空状态机聚合相结合的双轨制：

| 评估维度 | 核心检验目标 | 异常判定红线 (Penalties) |
| :--- | :--- | :--- |
| **1. 连续一致性 (Consistency)** | 时空流逝、物理法则、角色性格底色、作息与行囊逻辑的一贯性。 | 发生异地瞬移、已消耗物品凭空复原、违背角色固有生理画像。 |
| **2. 叙事观赏性 (Narrative Quality)** | 文学描摹的感官沉浸感、第三人称有限视角遵循度、节奏波澜与起承转合。 | 陷入模板化复读、机械报菜名、破坏有限视角的全知上帝视角泄漏。 |
| **3. 社交网络活性 (Social Dynamics)** | 随探索游历自然结识专属 NPC，人际羁绊好感度动态演变，时过境迁弱关系自然衰退归档。 | 异地凭空在场、100 刻无新角色沉淀、所有角色好感恒定死板。 |
| **4. 角色成长弧光 (Character Arc)** | 阶段目标完成与心境成熟度演进，物质与能力积淀，核心执念的深化。 | 100 刻目标无进展、心境始终停留在初始状态无任何波澜。 |

## 2. 自动化推演驱动器规范 (`backend/scripts/auto_driver.py`)

面对前端【智能续写 / +1h / +6h / +24h / 突发事件】纯按钮控制体系，自动化驱动器模拟现实生活节律状态机（Circadian & Drama State Machine）进行智能调度：

1. **休眠快进优先树 (+6h / +24h)**：
   - 当检测到角色精力值 `stamina <= 20` 或 `is_sleeping == 1` 时，强制触发 `hour_6` 深度休眠恢复。
   - 当虚拟时间处于角色的自适应作息窗口（如深夜 23:00~06:00）且距上次休息超过 6 刻时，触发阶段跨夜快进。
2. **戏剧张力与变数打破 (trigger_incident)**：
   - 当连续 8 刻处于相同地点且无目标完成、且距离上次突发事件超过 10 刻时，调用 `trigger_inciting_incident` 由 AI 自主衍生题材自适应变数。
3. **日常步幅推进 (continue vs step)**：
   - 75% 权重调用自由续写（由大模型自主研判行动时间尺度与步长）。
   - 25% 权重调用微步进 (+1h) 进行微观场景探索。
4. **断点持久化与无损继承**：
   - 为每个角色采用统一长程命名：`backend/logs/simulation_journal_{角色名}.txt`；
   - 自动检测并无损继承旧批次中的丰富元数据（真实耗时、决策归因、背包、生理状态）；
   - 后续无论从 20 刻推向 40 刻还是 100 刻，均在同一文档中紧随其后实时追加，确保全量数据一字不漏。

## 3. 单文件独立 HTML 评测报告规范 (`backend/scripts/report_generator.py`)

为了直观呈现 100 刻推演的全景成果，报告生成器输出零依赖、可离线双击打开的 HTML 文件：

- **绝对无 Emoji 铁律**：所有状态标识均采用纯 CSS/SVG 矢量标签与高对比度微徽章。
- **深色科技新拟态视觉 (`docs/05_UI_UX_NEUMORPHIC_SPEC.md`)**：全面遵循深色新拟态设计令牌，双向光源暗凸（`--shadow-flat`）与内凹刻痕（`--shadow-inset`），严禁刺眼纯色。
- **角色智能检索**：支持 `--name` 模糊搜索，若有同名角色或未传参自动弹出交互式列表供选择。
- **内嵌功能核心板块**：
  1. **宏观看板**：历时虚拟时间跨度、总字数、平均单刻字数、总健康评分徽章。
  2. **四维评分与诊断**：LLM-as-a-Judge 深度诊断看板，输出总评概述、四维（一致性、观赏性、社交生态、角色弧光）量化进度条与深度解析、核心高光转折。
  3. **连续贯穿的竖向客观时间疏密时间轴 (Vertical Proportional Timeline)**：
     - **全天数连续排布**：单条垂直主轴纵向贯穿所有推演天数，跨天时以 Neumorphic 徽章优雅衔接，告别横向切分的断裂感；
     - **严格客观时间等比连续疏密映射 (0------00---0 哲学)**：卡片垂直间距与客观真实时间跨度 $\Delta t$ 采用严格等比线性函数：
       - 半小时（0.5h）：间距仅 12px，卡片紧密贴合堆叠（`00`），直观体现高频连续行动的密集节奏；
       - 1 小时（1.0h）：间距等比拉开至 60px，带客观推进徽章；
       - 1.5 小时（1.5h）：间距等比拉开至 107px，轴线上自动标出沿途经过的整点刻度；
       - 2.25 ~ 2.5 小时（2.25h~2.5h）：间距拉开至 178px ~ 202px（**比半小时拉开近 15~17 倍超大视觉落差**），轴线延展并悬浮客观流逝胶囊；
       - 6.0 ~ 8.5 小时（休眠/跨夜）：平滑延展为 334px ~ 404px，呈现深度睡眠与跨夜的广阔时空纵深；
     - **主轴客观时间整点标尺刻度 (Hour Ruler Notches)**：在间隔 $\ge 0.9$h 的拉长主轴线上，自动根据客观时间插值标注沿途经过的整点时间（如 `11:00`、`12:00` 等精致工业刻痕与低对比度时刻数字），让时间轴成为一条真正客观流动的 24 小时自然日卷轴；
     - **点击时间点展开查验 (Click to Inspect)**：默认单行紧凑预览，点击任意时间点原位展开微观场景、实时生理、事实因果骨架 (Plot Beat) 与第三人称文学正文；
     - **全景精力微型波形**：标头保留连续心电波形图作为全景观测。
      - **多维世界事件里程碑 (Timeline Milestone Stream)**：在时间轴节点左侧/头部直接显化当刻发生的重大客观突破，包括目标达成 (🎯)、新结识角色 (🤝)、好感度提升 (❤️)、随身道具流转 (📦)，无需展开卡片即可一览角色命运转折。
  4. **宏观地理据点迁徙链 (Macro Location Trajectory)**：
     - **LLM 地点归类分类 (Location Clustering)**：大模型裁判在评估时同步对所有微观房间/角落进行智能提炼，映射至 2~6 个核心一级宏观据点；
     - **启发式兜底归纳**：离线或降级模式下基于层级分隔符（`·`、`-`）及核心场景词实现前缀聚类；
     - **足迹高内聚折叠**：连续多刻处于同一宏观据点合并为单个生活阶段卡片，卡片内完整展示建筑内穿梭的细分场景流。
   5. **社交关系网络演化与好感度历程 (Social Graph Dynamics & Affinity Trajectory)**：
      - **好感度演化追踪**：突破单纯结识展示，全量记录 NPC 好感度实时跃迁（量化分级：莫逆之交、技术盟友、心照不宣、提防对立）；
      - **互动事件因果流**：每个角色卡片内嵌折叠历史，完整溯源历次好感度增减的具体事件事实（如“以学术算式折服双子”、“草药温室掩护偷取幼茎”）；
      - **亲密关系降序榜**：按累计互动频次与好感度综合加权，优先聚焦核心羁绊角色。
  6. **行囊物品生命周期流水**：增、删、断舍离与当前随身 8 件上限状态。
  7. **角色成长与阶段目标达成**：已完成与进行中目标清单。

## 4. 快速运行指令清单

```bash
# 1. 推进指定角色至 20 刻或 100 刻 (按名称搜索，全量记录自动累积至同一 txt)
backend\venv\Scripts\python.exe backend/scripts/auto_driver.py --name 菲比·卡文迪许 --target-ticks 20

# 2. 生成指定角色的单文件独立 HTML 评测报告 (含大模型裁判深度评分与智能地点归类)
backend\venv\Scripts\python.exe backend/scripts/report_generator.py --character-id c-1889c2e8

# 3. 离线快速生成 (跳过 LLM 裁判，使用基准客观状态流水与启发式地点归类)
backend\venv\Scripts\python.exe backend/scripts/report_generator.py --character-id c-1889c2e8 --no-llm
```
