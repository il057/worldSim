# 07 长程推演质量评估与基准报告规范 (docs/07_EVALUATION_AND_BENCHMARK.md)

本文档规范了系统在经历 100+ 刻长跨度推演后的**长程一致性验证**、**拟真生活节律自动化调度**与**单文件独立 HTML 评测可视化报告**架构体系。

---

## 1. 核心评估四大维度规范 (Four-Dimension Evaluation Matrix)

长程推演（100 刻）的质量验证杜绝依赖纯人工肉眼抽检，系统采用工业级 **LLM-as-a-Judge（大模型裁判）** 与客观时空状态机聚合相结合的双轨制：

| 评估维度 | 核心检验目标 | 异常判定红线 (Penalties) |
| :--- | :--- | :--- |
| **1. 连续一致性 (Consistency)** | 时空流逝、物理法则、角色性格底色、作息与行囊逻辑的一贯性。 | 发生异地瞬移、已消耗物品凭空复原、违背角色固有生理画像。 |
| **2. 叙事观赏性 (Narrative Quality)** | 文学描摹的感官沉浸感、第三人称有限视角遵循度、节奏波澜与起承转合。 | 陷入模板化复读、机械报菜名、破坏有限视角的全知上帝视角泄漏。 |
| **3. 社交网络活性 (Social Dynamics)** | 随探索游历自然结识专属 NPC，人际羁绊好感度动态演变，时过境迁弱关系自然衰退归档。 | 异地凭空在场、100 刻无新角色沉淀、所有角色好感恒定死板。 |
| **4. 角色成长弧光 (Character Arc)** | 阶段目标完成与心境成熟度演进，物质与能力积淀，核心执念的深化。 | 100 刻目标无进展、心境始终停留在初始状态无任何波澜。 |

## 2. 自动化推演驱动器规范 (`backend/scripts/auto_driver.py`)

面对前端【智能续写 / +1h / +6h / +24h / 突发事件】纯按钮控制体系，自动化驱动器模拟现实生活节律状态机（Circadian & Drama State Machine）进行智能调度：

1. **休眠快进优先树 (+6h / +24h)**：
   - 当检测到角色精力值 `stamina <= 20` 或 `is_sleeping == 1` 时，强制触发 `hour_6` 深度休眠恢复。
   - 当虚拟时间处于角色的自适应作息窗口（如深夜 23:00~06:00）且距上次休息超过 6 刻时，触发阶段跨夜快进。
2. **戏剧张力与变数打破 (trigger_incident)**：
   - 当连续 8 刻处于相同地点且无目标完成、且距离上次突发事件超过 10 刻时，调用 `trigger_inciting_incident` 由 AI 自主衍生题材自适应变数。
3. **日常步幅推进 (continue vs step)**：
   - 75% 权重调用自由续写（由大模型自主研判行动时间尺度与步长）。
   - 25% 权重调用微步进 (+1h) 进行微观场景探索。
4. **断点持久化与无损继承**：
   - 为每个角色采用统一长程命名：`backend/logs/simulation_journal_{角色名}.txt`；
   - 自动检测并无损继承旧批次中的丰富元数据（真实耗时、决策归因、背包、生理状态）；
   - 后续无论从 20 刻推向 40 刻还是 100 刻，均在同一文档中紧随其后实时追加，确保全量数据一字不漏。

## 3. 单文件独立 HTML 评测报告规范 (`backend/scripts/report_generator.py`)

为了向面试官或评审人直观呈现 100 刻推演的全景成果，报告生成器输出零依赖、可离线双击打开的 HTML 文件：

- **绝对无 Emoji 铁律**：所有状态标识均采用纯 CSS/SVG 矢量标签与高对比度微徽章。
- **深色科技新拟态视觉**：采用微毛玻璃深色卡片与流光强调色。
- **角色智能检索**：支持 `--name` 模糊搜索，若有同名角色或未传参自动弹出交互式列表供选择。
- **内嵌功能板块**：
  1. **宏观看板**：历时虚拟时间跨度、总字数、平均单刻字数、总健康评分徽章。
  2. **四维评分与诊断**：雷达进度条、裁判总评、维度优势与改进建议、高光时刻节点。
  3. **纯 SVG 生理精力心电图**：直观展示 100 刻昼夜循环中的精力起伏波形。
  4. **地理足迹迁徙轨迹链**：按时间先后顺序展示主角停留过的全部场景与驻留刻数。
  5. **社交关系网络图鉴**：新结识 NPC 卡片、好感度进度条、常驻地与归档状态。
  6. **行囊物品生命周期流水**：增、删、断舍离与当前随身 8 件上限状态。
  7. **剧情长卷编年史抽样**：可阅读的小说切片流。

## 4. 快速运行指令清单

```bash
# 1. 推进指定角色至 40 刻或 100 刻 (按名称搜索，全量记录自动累积至同一 txt)
backend\venv\Scripts\python.exe backend/scripts/auto_driver.py --name 萝西·瓦伦泰 --target-ticks 40

# 2. 生成指定角色的单文件独立 HTML 评测报告 (离线模式)
backend\venv\Scripts\python.exe backend/scripts/report_generator.py --name 萝西·瓦伦泰 --no-llm

# 3. 生成指定角色的 HTML 报告 (含大模型裁判深度量化评分)
backend\venv\Scripts\python.exe backend/scripts/report_generator.py --name 萝西·瓦伦泰
```

# 3. 离线快速生成 (跳过 LLM 裁判，仅基于客观状态流水)
backend\venv\Scripts\python.exe backend/scripts/report_generator.py --no-llm
```
